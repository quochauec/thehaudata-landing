Step 1 of 5

Install SQL Express

  1. Download SQL Express 2025

    Get it from Microsoft: SQL Express 2025 download page.

  2. Choose these installation options and wait until it is done

    Got this error? Download this Microsoft program, double-click it to run, then retry the SQL Express install:
    https://aka.ms/vs/17/release/vc_redist.x64.exe

  3. Copy the connection string to your sticky notes

    You need it to connect from VS Code in Step 3.

Step 2 of 5

Install Visual Studio Code

VS Code is a free, powerful code editor. We use it to write SQL queries and manage data.

  1. Download and run the installer

    If you are not familiar with installing software, watch this video.

    Open the official VS Code website→ Click the large blue Download→ Run VSCodeSetup.exe→ Accept license, Next

  2. Tick these boxes on the "Select Additional Tasks" screen

    • Create a desktop icon (optional, but handy)
    • Add "Open with Code" action to the Windows Explorer file context menu
    • Register Code as an editor for supported file types
    • Add to PATH, so you can launch VS Code from any terminal

    Click Next, then Install. Launch VS Code from its icon.

Step 3 of 5

Connect VS Code to SQL Server Express

You add an extension so VS Code can talk to your database.

  1. Install the MSSQL extension

    • Open VS Code.
    • Click the Extensions icon on the left sidebar (it looks like four squares).
    • Search for SQL Server (mssql).
    • Click Install on the one published by Microsoft.

  2. Open the SQL Server tab

    A new SQL Server icon (a database) appears in the left sidebar. Click it.

  3. Add a new connection

    Click the + (plus) next to the "Connections" header.

  4. Answer the prompts at the top of the window

    • Server name: your SQL Express instance. Examples: localhost\SQLEXPRESS (usually Windows) or localhost (usually MacBook).
    • Database name: leave blank and press Enter, or type the database you want.
    • Authentication type: Windows Authentication is usually easiest for a local Express install. SQL Login also works.
    • Profile name: a friendly name, for example TheHauData Class.

  5. Connect

    VS Code now tries to connect. If it works, your server and databases appear in the SQL Server sidebar.

Check: your server is listed in the SQL Server sidebar.
Step 4 of 5 · Method 1 Recommended

Import the databases in the VS Code UI

If you already restored the Track 1 and Track 2 .bak files, you do not need to import anything else. A .bak file is a full backup of a whole database, so it is the easiest way to load the course datasets.

  1. Download the backup files

    Download them from the Dataset folder (link in the Class Checklist).

  2. Copy the .bak file to the C drive or the Backup folder

    Choose only one option.

    Option 2 is the default path for .bak files:
    C:\Program Files\Microsoft SQL Server\MSSQL16.SQLEXPRESS\MSSQL\Backup

  3. Open the restore window

    Right-click your connection (it must be active, "green mode")→ Restore Database→ Backup Location: Backup file
    No restore option on your computer? Turn it on:
    1. Click the settings icon at the bottom left corner.
    2. Choose Workbench.
    3. Turn on Enable Preview Feature.
    4. Close the settings window and refresh.

  4. Go to the folder from step 2 and choose the .bak file

  5. Click Restore and wait for the status

    Repeat for each track.

Method 2: Restore with a T-SQL command Advanced

For people who cannot import with the UI. A .bak file is a full backup of a whole database.

  1. Create a data folder on the C drive

    For example C:\Data. Put the .bak files in it.

  2. Open a new query

    In the VS Code SQL Server sidebar, right-click your connected server (or the database folder) and select New Query.

  3. Paste and run this command

    Crucial: replace [NewDatabaseName], [OldDatabaseName] and the file paths with your actual values. Your .bak file name will be different from the example.
    T-SQL
    RESTORE DATABASE [TheHauData_Track1] --Your database name

FROM DISK = 'C:\Data\TheHauData_Track1-20251220-10-21-31.bak' --Your actual bak file path

WITH

   MOVE 'TheHauData_Track1' TO 'C:\Data\TheHauData_Track1.mdf', --Automatically created file

   MOVE 'TheHauData_Track1_log' TO 'C:\Data\TheHauData_Track1_log.ldf', --Automatically created file

   REPLACE;

RESTORE DATABASE [TheHauData_Track2] --Your database name

FROM DISK = 'C:\Data\TheHauData_Track2-20251220-10-22-18.bak' --Your actual bak file path

WITH

   MOVE 'TheHauData_Track2' TO 'C:\Data\TheHauData_Track2.mdf', --Automatically created file

   MOVE 'TheHauData_Track2_log' TO 'C:\Data\TheHauData_Track2_log.ldf', --Automatically created file

   REPLACE;
Method 3a: Import a .csv with the Import flat file wizard Optional

For extra data beyond the course datasets, or if you cannot import from a .bak file. One .csv file is one table.

  1. Download each .csv file

    Download the tables as .csv from Course Documentation.

    The datasets are in the folder Documentation → Practice Datasets. If you cannot open the folder, click request access or contact your mentor.

  2. Right-click the target database and choose Import flat file

    Choose the connection and database where the new table should be saved.

  3. Enter the schema, table name and .csv location

    • 3.1 Double check the Target database.
    • 3.2 Choose the .csv file path on your computer.
    • 3.3 Choose the schema and type the table name.

  4. Preview the data

    Check that you are importing the right file.

  5. Choose a data type for each column

    • 5.1 Review each table's data types carefully.
    • 5.2 Make the data size larger than the recommended data type.
    • 5.3 Click Import Data.
    Tips: Text column → nvarchar(Max). Number column → Float.
Method 3b: Import a .csv with BULK INSERT Optional

Before you import, create the empty table with the right column names and types, or truncate the existing table. Open a New Query against your target database.

Create a brand new table from a .csv file

Example: a table named match in a database named testing.

Step 0. Select your destination database. If it is a new database, create it first:

T-SQL
CREATE DATABASE testing

Step 1. Create an empty table with the correct column names and data types.

T-SQL
-- Step 1: Create empty table (with proper schema design)
CREATE TABLE [testing].dbo.match (
    [year] BIGINT NOT NULL,
    [host_country] NVARCHAR(MAX) NULL,
    [winner] NVARCHAR(MAX) NULL,
    [runners_up] NVARCHAR(MAX) NULL,
    [third] NVARCHAR(MAX) NULL,
    [fourth] NVARCHAR(MAX) NULL,
    [goals] NVARCHAR(MAX) NULL,
    [qualified_team] NVARCHAR(MAX) NULL,
    [match_played] BIGINT NULL
);

Step 2. Insert the data from the .csv file.

T-SQL
--Step 2: Insert data to new table from csv file
BULK INSERT [testing].dbo.match ---your table name
FROM 'D:\Class\3. Practice Datasets\Datasets - CSV\3. World+Cup\world_cups.csv' -- Use the full, local path to your CSV file
WITH (
    FIELDTERMINATOR = ',',  -- Separator used in your CSV (e.g., comma)
    ROWTERMINATOR = '\n',   -- Line break used in your CSV (usually '\n' or '\r\n')
    FIRSTROW = 2            -- Start loading data from the second row (to skip the header)
);

Overwrite data in a current table

Step 1. Truncate the current table (deletes the data only, keeps the structure).

T-SQL
TRUNCATE TABLE dbo.YourTableName;
--Example
TRUNCATE TABLE [testing].dbo.match;

Step 2. Insert the data from the .csv file.

T-SQL
-- --Step 2: Insert data to new table from csv file
BULK INSERT [testing].dbo.match
FROM 'D:\Class\3. Practice Datasets\Datasets - CSV\3. World+Cup\world_cups.csv' -- Use the full, local path to your CSV file
WITH (
    FIELDTERMINATOR = ',',  -- Separator used in your CSV (e.g., comma)
    ROWTERMINATOR = '\n',   -- Line break used in your CSV (usually '\n' or '\r\n')
    FIRSTROW = 2            -- Start loading data from the second row (to skip the header)
);
Step 1 of 4

Install the base software

Set up SQL Server with Docker and connect through Visual Studio Code (new version).

  1. Install VS Code and the mssql extension

    Download from code.visualstudio.com/download and install. Then open Extensions in VS Code, search SQL Server (mssql) and install it.

  2. Install Docker Desktop and the SQL containers extension

    Download Docker Desktop from docker.com/products/docker-desktop. Open Docker, go to Extensions, search SQL containers and install it.

Step 2 of 4

Create the SQL Server container

  1. Click New Deployment

    Open VS Code, click the mssql extension icon on the left toolbar, then choose New Deployment.

  2. Choose "Create a Local Docker SQL Server"

  3. Set a password and click Create Container

    Write your password down. You need it to connect.

  4. Click Next

    If the setup shows "Failed", do not worry. Let it keep running.

  5. Check Docker Desktop

    Go back to Docker Desktop. sql_server_container should be there with the status RUNNING. If so, the container is created.

Step 3 of 4

Connect the database to VS Code

  1. Copy the connection string from Docker

    In Docker Desktop, click Copy Connection String on the row of the container you just created.

  2. Add Connection, then Load from Connection String

    Back in VS Code, in the mssql tab, choose Add Connection and click Load from Connection String.

  3. Paste the string and click Load

  4. Enter your password and click Connect

    Use the password you made in Step 2.

  5. Look for localhost,1433

    The connection worked when the server localhost,1433 shows in the Connections list.

Step 4 of 4

Restore the course data

The container is a separate mini-computer, so you first copy the .bak file into it, then restore from there.

Download .bak→docker ps→docker cp into /tmp→Restore in VS Code→Database appears

  1. Download the .bak files

    Download the course backup files (.bak) and save them in your Downloads folder.

  2. Find your container ID

    Open Terminal and type:

    terminal
    docker ps

    Copy the CONTAINER ID of sql_server_container.

  3. Copy the path of the .bak file

    Find the downloaded .bak file, right-click it and choose Copy to get its path.

  4. Copy the file into the container

    Back in Terminal, use your own path and container ID:

    terminal
    docker cp [file_path_you_copied] [CONTAINER_ID]:/tmp

# example
docker cp /Users/Bi/Downloads/2.Datasets/bak-2022version/TheHauData_Track1.bak 0704830623ce:/tmp

  5. Right-click the connection and choose Restore Database (Preview)

    In VS Code, right-click localhost,1433.

  6. Tick Backup File and click Browse files

  7. Open the tmp folder, pick your .bak file and restore

    Repeat the same process for the other tracks (for example Track 2) until you finish.

Check: Track 1 and Track 2 databases are listed under localhost,1433.
